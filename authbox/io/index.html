Top-level I/O compatibility namespace for xtra/authbox/include/pki/files.hpp.

The C++ header lives under include/pki/files.hpp, but the helpers are exported in authbox::io. Keep the real implementation in src/pki/files.rs and expose this small namespace shim instead of folding the file helper surface into an unrelated module.
