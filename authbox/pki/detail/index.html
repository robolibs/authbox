Compatibility helpers for the C++ authbox::pik::detail namespace.

The C++ headers reopen authbox::pik::detail from several PKI headers. This module starts that shared namespace with the PEM/base64 helpers from xtra/authbox/include/pki/pem.hpp, pki/asn1_utils.hpp, pki/oid_registry.hpp, and pki/distinguished_name.hpp while keeping the real surfaces in their mirrored Rust modules.
