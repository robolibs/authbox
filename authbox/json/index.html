Shared JSON helpers for the Rust authbox port.

The C++ tree vendors include/json.hpp; this Rust module keeps the same top-level concern without cloning that C header’s parser/DOM internals. Strict JSON is delegated to serde_json; permissive JSON5-shaped input is delegated to json5. The local Json enum keeps DID/PKI call sites stable without hiding a custom parser in those modules.
